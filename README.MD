# 极速 MP3 转 MP4 批量引擎 (YouTube 音频存档专用)

这是一个基于 Python 和 MoviePy 开发的桌面工具，旨在帮助用户快速、批量地将 MP3 音频文件转换为带有静态背景图片的 MP4 视频。

该工具特别为需要在 YouTube、Bilibili 等视频平台存档音频内容的用户设计。通过将视频帧率强制设置为 1 FPS（每秒 1 帧），它能在保证音频质量的同时，生成体积极小的视频文件，极大地节约了上传时间和云端存储空间。

---

## ✨ 主要特性

- **批量处理**: 支持一次性选择多个 MP3 文件，实现全自动转换。
- **极简操作**: 提供基于 Tkinter 的图形用户界面（GUI），三步即可完成所有设置。
- **极速渲染**: 核心算法强制使用 1 FPS 渲染，专注音频封装，处理速度极快。
- **轻量高效**: 基于强大的 `MoviePy` 库，底层调用 FFmpeg，稳定可靠。
- **实时日志**: 在界面中提供详细的转换日志，实时跟踪处理进度和结果。
- **跨平台**: 基于 Python 编写，可在 Windows, macOS 和 Linux 上运行。

## 📦 环境要求与安装

本项目依赖 Python 3 和 `MoviePy` 库。

1.  **确保您已安装 Python 3。**

2.  **安装 MoviePy 库:**
    打开终端或命令行工具，运行以下命令：
    ```bash
    pip install moviepy
    ```
    *MoviePy 会在首次执行时自动下载所需的 FFmpeg 组件（如果系统中没有的话）。*

## 🚀 如何使用

1.  下载或克隆本项目到您的本地。
2.  在项目根目录下，通过命令行运行主程序：
    ```bash
    python MP3toMP4.py
    ```
3.  在弹出的程序窗口中，按照指引操作：
    - **步骤 1**: 点击 **"1. 🎵 选择批量 MP3 文件"** 按钮，选择一个或多个 MP3 文件。
    - **步骤 2**: 点击 **"2. 🖼️ 选择背景图片 (JPG/PNG)"** 按钮，选择一张将作为视频背景的静态图片。
    - **步骤 3**: 点击 **"3. 📁 选择 MP4 输出文件夹"** 按钮，指定转换后视频的保存位置。
    - **步骤 4**: 点击 **"4. ▶ 开始极速渲染生成 MP4"** 按钮，启动转换任务。
4.  等待处理完成。您可以在界面下方的日志区查看每个文件的处理状态。任务结束后，前往您指定的输出文件夹即可找到所有生成的 MP4 文件。

## 📝 开发日志 (Changelog)

### v2.1 (MoviePy 2.x 适配版)
- **语法重构**: 完美适配 MoviePy v2.0+ 最新版 API。将废弃的 `set_duration` 和 `set_audio` 替换为全新的 `with_duration` 和 `with_audio` 链式调用方法，彻底解决 Attribute 报错崩溃问题。
- **核心引擎升级**: 直接从 `moviepy` 根目录引入核心类，摒弃了已被官方移除的 `moviepy.editor` 子模块。

### v1.0 (极速渲染奠基版)
- **架构确立**: 引入轻量级 MoviePy 作为核心调度引擎，底层隐式调用 FFmpeg 进行音视频混流封装。
- **核心算法优化**: 针对“音频存档”的业务特性，强制覆写视频帧率为 1 FPS（每秒 1 帧静态图）。
- **批量自动化**: 集成 Tkinter GUI，实现了三步极简工作流。
